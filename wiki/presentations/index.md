# Presentations

Talks, video essays, lectures and recorded demos. The presenter is the source: production figures and outcome claims are presenter-reported unless the page records independent corroboration, and each page marks them as such. A conference talk and a standalone video sit here on the same terms — what defines the record is one presenter making claims in a recorded presentation, not the venue or the platform.

- [[projects/all-code-is-slop-except-mine|All Code Is Slop (Except Mine)]] — Lauren Tan (AI Engineer Code Summit) on Grok Bot at SpaceXSI: 11,000 PRs in a month at ~0.5% reverts, bought by converting every agent correction into a deterministic check instead of a rule.
- [[projects/death-of-the-code-review|The Death of the Code Review]] — Laurie Voss (AI Engineer World's Fair) on the code-review bottleneck: agents wrote 741% more code and shipped 30% more software, and review is being rebuilt as an engineered system.
