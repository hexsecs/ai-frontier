# Techniques

- [Verification and evidence](./verification-and-evidence.md) — Checking agent claims against gathered evidence — executable tests, replay scorers, provenance gates — with warrant bounded by the scope actually exercised.
- [Adaptive recovery](./adaptive-recovery.md) — Recovery succeeds when repair scope follows the contribution graph, not the failure's location; local repair alone scores below doing nothing.
- [Agent skills and memory](./agent-skills-and-memory.md) — Persistent skills and memory let frozen models improve when admission to the store is gated; ungated memory and unmeasured stores return nulls.
- [Multi-agent orchestration](./multi-agent-orchestration.md) — Under source-level mining the orchestration theme dissolved: the corpus shows per-system mechanisms, not a shared technique with transferable evidence.
- [Evaluation and simulation](./evaluation-and-simulation.md) — How this corpus evaluates agents — benchmark construction, trajectory scoring, adversarial testing, instrument audits — and the lenses that discount its scores.
- [Embodied and scientific agents](./embodied-and-scientific-agents.md) — Agents acting on instruments and physical systems, where feedback arrives as measurement, actions carry real cost, and evidence tiers bound every claim.
- [Secure agent operations](./secure-agent-operations.md) — How this corpus runs agents under security constraint — policy gateways, structural write channels, provenance-gated detection — and what was measured.
- [Generative interfaces](./generative-interfaces.md) — Agents propose declarative UI or actions; a trusted host validates against a pre-declared catalog or policy before anything renders or runs.
