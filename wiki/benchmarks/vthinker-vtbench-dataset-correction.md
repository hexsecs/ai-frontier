# VTBench public dataset correction

**Primary source:** https://github.com/We-Math/V-Thinker. **Source date:** 2026-11-19.

## Demonstrated capability and mechanism

Maintainers disclosed that the publicly downloadable Instruction-Guided Interaction subset was a non-final export differing from the dataset used in experiments. A dataset export/version mismatch breaks the mapping between published score and publicly reproducible evaluation.

**Reusable concept:** Benchmark artifact identity and reproducibility. Exploratory firsthand reproducibility incident, not a new agent algorithm. Correction pending as of November 20; no independent audit.

## Boundaries and test

Hash available dataset artifacts, compare sample identifiers and defer reproduction claims until a pinned corrected release is available.

This is a proposed experiment, not an independently reproduced result. See [[briefings/2026/11/2026-11-20]] and [[concepts/verified-completion-vs-apparent-success]] for comparisons and acceptance limits.
