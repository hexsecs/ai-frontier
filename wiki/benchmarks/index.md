# Benchmarks

Choose an instrument by its tasks and acceptance rules. Scores across these protocols are not a common ranking; see [[concepts/protocol-relative-scores]].

- [[projects/tandembench|TandemBench]] — Benchmark that asks decision models to pick optimal two-agent cooking plans and to notice when every supplied plan is suboptimal.
- [[projects/masbench|MASBench]] — Multi-agent collaboration benchmark that isolates protocol, memory and routing effects under deliberately partial observability.
- [[projects/st-bench|ST-Bench]] — Benchmark of 100 Earth-science analysis tasks and 2,067 queries measuring whether multi-agent systems beat a single agent, and at what cost.
- [[projects/weavebench|WeaveBench]] — Peer-reviewed EMNLP 2026 benchmark of 114 hybrid GUI/CLI/code desktop tasks with a trajectory-aware judge; best model-runtime PassRate 41.2%.
- [[projects/crossswe|CrossSWE]] — Benchmark of 171 real-world cross-repository joint-development tasks where only coordinated changes across interdependent repositories pass.
- [[projects/agentswe|AgentSWE]] — Benchmark of 25 commissions testing whether coding agents deliver the agent a natural-language requirement describes, graded on held-out cases.
- [[projects/agenticbench|AgenticBench]] — Independent rolling benchmark that scores AI coding-agent harnesses on what they do with local files, egress, telemetry and secrets.
- [[projects/codespecweave|When Requirements Interact: Scaling Long-Horizon Coding via Interdependent Specifications]] — Synthetic coding tasks with interdependent requirements, grounded in real-repo seeds; 73.9% of pilot candidates had flawed tests.
- [[projects/dynarev|DynaRev: Benchmarking Web Agents under Dynamic Goal Revision]] — DynaRev: 181-task web-agent benchmark delivering additive and override goal revisions at semantic milestones, scored for correctness, responsiveness, and cost.
- [[projects/envos|EnvOS: Auditing Computer-Use Agents When the World Moves On — Phenomenon-Based Task Construction, Certification, and Evidence-Based Evaluation]] — Framework that builds and certifies computer-use environments changing mid-task, then audits each verdict from archived evidence; tested on stale values.
- [[projects/seq-k|Seq@K: Evaluating Language Models Under Sequential Feedback]] — Evaluation protocol measuring whether a model solves a task within K sequential attempts, given feedback after each failure; rankings diverge from Pass@K.
- [[projects/prefix-executability|Prefix Executability: Evaluating Tool-Using Agents Beyond Final Success]] — Successful episodes often pass through invalid prefixes: final success and prefix executability rank the same agents differently.
- [[projects/fincosmos|FINCOSMOS: An Open-World Evaluation Paradigm for Agents in Finance]] — Open-world agent benchmark for finance: hidden intent, self-sourced Web data, point-in-time backtests and 15 veto checks; no session accepted in 150 runs.
- [[projects/expertcrowd-swe|ExpertCrowd-SWE]] — One hundred expert-authored engineering tasks use calibrated executable graders and must-pass merge blockers.
- [[projects/workflowarena|WorkflowArena: Executable Multi-Agent Orchestration]] — A 145-task benchmark evaluates model-authored worker delegation, workflow organization and integrated deliverable verification.
- [[projects/serverbench|ServerBench: Agent-Designed LLM Serving Systems]] — Coding agents optimize LLM serving systems under verified workload, latency and GPU-cost constraints.

- [[projects/abc-bench-backend-coding|ABC-Bench]] — External API acceptance for deployed backend services across eight languages and 19 frameworks.
- [[projects/agenticdatabench|AgenticDataBench]] — Fine-grained data-science skill coverage and workflow scoring across 15 domains.


- [VTBench public dataset correction](./vthinker-vtbench-dataset-correction.md) — Non-final public interaction subset disclosed November 19; benchmark version integrity.
