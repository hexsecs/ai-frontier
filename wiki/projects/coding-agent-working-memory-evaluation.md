# Measure Before You Manage: Coding Agent Working Memory

**Source:** https://arxiv.org/abs/2608.31057. **Source date:** 2026-08-31. 

## Mechanism and demonstrated scope

Object-aware compression and retrieval policies evaluated against semantic categories and held-out trajectories. The reusable boundary is [[concepts/information-content-dominance]]; this implementation does not by itself establish that other systems share its results.

## Evidence and limits

Author-reported evaluation of 55 archived trajectories; calibration gains may not transfer to held-out tasks. The described behavior should be treated as implementation documentation or author-reported findings, not independent replication.

## Proposed bounded experiment

Replay 20 held-out coding traces under equal nominal token budgets, separately recording delivered context, management work and accepted task outcomes. No experiment is reported as executed here.
