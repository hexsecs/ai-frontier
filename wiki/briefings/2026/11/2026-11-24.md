# Agentic AI Frontier — November 24, 2026

**Frontier signal:** Reusable orchestration, browser authority and executable skill retention are distinct mechanisms. Three source-backed discoveries are included; two additional candidate papers could not be retrieved during recovery and are excluded rather than treated as verified. Sources were rechecked November 25; older discoveries are labeled.

## 1. The Agentic Scientist

**Source date:** October 13, 2026 (older research). **Primary URL:** https://arxiv.org/abs/2610.18933. **Canonical record:** [[projects/the-agentic-scientist]].

**Capability and mechanism:** The authors describe staged research from idea generation through sandboxed experiments, baseline and ablation construction, analysis and reporting. A meta-controller coordinates workers and checks stage rubrics.

**General concept and novelty:** Meta-controller coordinates parallel coding agents across scientific research stages with rubric checks. Compare [[techniques/embodied-and-scientific-agents]].

**Evidence limits:** The abstract reports one accepted collaborative ALIFE paper; this is not a general measure of scientific validity. Full methodology and independent replication were not verified.

**Practical implication and proposed reproducible experiment:** Compare single-agent and orchestrated runs on five known-answer experiments, with fixed budget and independent scoring of conclusions and artifacts. Not executed.

## 2. Browsentic

**Source date:** Repository discovery November 24; release date unverified. **Primary URL:** https://github.com/imshaikot/browsentic. **Canonical record:** [[projects/browsentic]].

**Capability and mechanism:** The README describes a browser side panel driven by existing local coding-agent CLIs and optional MCP access to the same browser. This reuses an authenticated browser context rather than creating a separate browser identity.

**General concept and novelty:** Local browser extension and agent CLI integration exposing a signed-in browser through optional MCP. Compare [[techniques/secure-agent-operations]].

**Evidence limits:** Maintainer documentation, inspected November 25; original release date and access enforcement across routes remain unverified.

**Practical implication and proposed reproducible experiment:** Use an isolated browser profile and 20 mock-site tasks; compare direct and MCP routes for unauthorized effects, credential exposure and task completion. Not executed.

## 3. ASPIRE robotics

**Source date:** October 2026 v1.0 (older release). **Primary URL:** https://github.com/NVlabs/ASPIRE. **Canonical record:** [[projects/aspire-robotics]].

**Capability and mechanism:** ASPIRE treats skill code refinement as continual learning and parallel practice as distributed training. The README reports 99% success on 80 LIBERO-Pro tasks for v1.0.

**General concept and novelty:** Coding agents refine executable sensorimotor skills, storing improvements in a skill repository. Compare [[techniques/agent-skills-and-memory]].

**Evidence limits:** Author-reported benchmark result; no independent replication or proof of safe physical operation. Full evaluation protocol was not inspected.

**Practical implication and proposed reproducible experiment:** In simulation, compare frozen and iteratively refined skills against fixed held-out tasks; record regressions, success and API cost. Not executed.

## Cross-item synthesis

Stage verification can improve the inspectability of scientific work, but does not itself establish scientific truth. Reused authenticated browser state creates a separate authority boundary. Persistent executable robot skills provide an external improvement artifact that can be regression tested. These are analytical comparisons, not a demonstrated integrated system.
