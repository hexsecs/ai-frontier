# Concepts

Cross-project phenomena and claims, mined from the KB's own deepened project pages (issue #2, mining pass 1, 2026-11-02). Each concept page names the project pages that supply evidence for it — and the pages that bound or complicate it.

- [Evaluator circularity](./evaluator-circularity.md) — When the evaluated system sits inside its own grading path, the score partly measures self-agreement.
- [Scoped assurance](./scoped-assurance.md) — A verification result holds only inside the scope actually exercised; headline numbers routinely outrun it.
- [Improvement lives in external state](./improvement-lives-in-external-state.md) — Agents in this corpus improve by editing persistent external state while model weights stay frozen.
- [Ground-truth fallibility](./ground-truth-fallibility.md) — The reference standards benchmarks score against contain measurable errors of their own.
- [Protocol-relative scores](./protocol-relative-scores.md) — A reported gap, and sometimes the ranking itself, is a property of the measurement convention chosen.
- [Information content dominates pipeline structure](./information-content-dominance.md) — In controlled contrasts, what information reaches the agent beats the pipeline structure around it.
- [Comparator construction shapes margins](./comparator-construction-shapes-margins.md) — A reported margin partly measures how its comparator was built — reimplementation fidelity, baseline selection policy, or literature numbers instead of re-runs.
- [Validation-tier gap](./validation-tier-gap.md) — A system's framing claims a higher validation tier — physical, production, independent — than the tier its evidence actually occupies.
- [Structural constraint over instruction](./structural-constraint-over-instruction.md) — Where these agent systems are trustworthy, the trust comes from structural limits the model cannot talk its way around, not from prompt instructions.
- [Capability locus](./capability-locus.md) — When an agent system improves, where does capability live — weights, harness, external state, or their interaction? One system now measures the decomposition.
- [Abstention as a first-class verdict](./abstention-as-first-class-verdict.md) — When a verdict is forced, systems invent one; making insufficient evidence an explicit, accounted outcome changes the failure shape of the decision.

- [Verified completion versus apparent success](./verified-completion-vs-apparent-success.md) — Independent acceptance is stronger than agent claims, user approval, transport acknowledgements, or merely declared checks.
- [Preservation-aware agent improvement](./preservation-aware-agent-improvement.md) — Strategy, harness and environment evolution must measure lost as well as newly solved tasks.
