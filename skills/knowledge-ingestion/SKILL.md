# knowledge-ingestion

Use AGENTS.md as normative policy. Resolve own canonical entity; search existing concepts, techniques, evaluations, signals, experiments, domains and question-led hubs. Preserve uid and created dates. Prefer substantive integration into existing passages; new concepts need distinct reusable questions and adequate evidence. Cross-project empirical generalizations require independent evidence and bounds. Record per-finding mechanism, concept, synthesis pages reviewed and disposition in PR metadata. Link full page IDs inline beside explained claims, preserve directional meaning, distinguish comparisons from established relations. Archive full historical narrative, not a condensed index. Update category and reading-path navigation. Preserve original claims unless explicit correction. No process prose, changelog, quotas or duplicated paragraphs. Verify substantive diff and source support.
